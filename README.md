# churn_analysis
End-to-end customer churn analysis and predictive modeling pipeline using machine learning to identify at-risk customers, uncover attrition drivers, and improve retention.
Customer Churn Analysis

End-to-end ML project to analyze attrition patterns, uncover churn drivers, and predict at-risk customers.

## Highlights
- **EDA & Preprocessing:** Clean, transform, and balance data
- **Modeling:** XGBoost, Random Forest, Scikit-learn
- **Insights:** SHAP-based feature importance & retention metrics
